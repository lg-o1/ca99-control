GENERAL FORMAT: F0 40 7F [fn] 08 02 [v1] [v2] [v3=part] [data...] F7

fn codes:
  0x10 = SET parameter
  0x02 = REQUEST parameter
  0x31 = MODE CHANGE
  0x32 = ACTION/SAVE
  0x7E = SYSTEM CONTROL

Part bytes: Main1=0x00, Main2=0x01, Layer=0x08, Lower=0x09, Global=0x0F, System=0x7F

SOUND SELECTION:
  F0 40 7F 10 08 02 55 00 [part] [msb] [lsb] [pc] F7
  e.g. Concert Grand (msb=0x79, lsb=0x00, pc=0x00) on Main1:

4. CROSS-REFERENCE WITH KNOWN DATA
=====================================
untouch/const.go format (OLDER protocol - different Kawai models):
  The untouch tool uses: F0 40 [ch] [cmd=10] [topic] [subtopic] [value(s)] F7
  where topics: instr=0x02, revrb=0x08, effct=0x09, vTech=0x11
  
  CA99 uses NEWER format with Gn=0x08, Mn=0x02, v1=0x50(VT)/0x55(Sound)/0x56(Music)
  
  Comparison of VT parameter addresses:
    untouch tCurv=vTech(0x11)/0x00 → CA99: fn=0x10/v1=0x50/v2=0x00 ✓ (same sub-addr!)
    untouch voicg=vTech(0x11)/0x01 → CA99: fn=0x10/v1=0x50/v2=0x01 ✓
    untouch dmpRs=vTech(0x11)/0x02 → CA99: fn=0x10/v1=0x50/v2=0x02 ✓
    untouch strRs=vTech(0x11)/0x04 → CA99: fn=0x10/v1=0x50/v2=0x04 ✓
    untouch koEff=vTech(0x11)/0x07 → CA99: fn=0x10/v1=0x50/v2=0x05 (different! KoEff=0x05, not 0x07)
    untouch topBd=vTech(0x11)/0x0A → CA99: fn=0x10/v1=0x50/v2=0x08 (Topboard=0x08, not 0x0A)
    untouch tmpmt=vTech(0x11)/0x0E → CA99: fn=0x10/v1=0x50/v2=0x0D ✓ (Temperament=0x0D)
    untouch keyVo=vTech(0x11)/0x10 → CA99: fn=0x10/v1=0x50/v2=0x0F ✓ (KeyVolume=0x0F)
  
  The untouch protocol wraps v1=0x11(vTech) as a group/topic byte; CA99 uses v1=0x50.
  The v2 (sub-addr) values mostly MATCH but the outer framing differs.
  CONCLUSION: untouch was designed for an older Kawai model; CA99 uses an evolved format.

PianoWorld layer format: F0 40 00 10 04 02 20 [s1][s2] F7
  CA99 Sound format:     F0 40 7F 10 08 02 55 00 [part] [msb][lsb][pc] F7
  Different: CA99 uses 3-byte (msb/lsb/pc) sound identifier vs 2-byte in older protocol.
